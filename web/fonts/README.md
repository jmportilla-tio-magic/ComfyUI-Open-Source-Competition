# Font assets

The studio serves these fonts locally so ComfyUI's offline mode does not need Google Fonts.

- DM Sans variable: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/dmsans), `DMSans[opsz,wght].ttf`, SIL Open Font License 1.1 in `dm-sans-OFL.txt`.
- Manrope variable: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/manrope), `Manrope[wght].ttf`, SIL Open Font License 1.1 in `manrope-OFL.txt`.

Both fonts are unmodified. Their licenses are independent of this repository's MIT source license.
