# Original Lightricks demo previews

These still previews were captured from the expanded video players on the original **Lightricks LTX-2.5 Creative Lab** Hugging Face model cards on October 24, 2026. They help readers recognize each capability before opening the original video.

- Each JPEG is a browser-captured still, cropped to the video area. It preserves the upstream comparison layout; no before/after content was generated by OpenPositive.
- Still images cannot demonstrate motion, looping, speed, or true HDR presentation. Use the linked original videos for those properties.
- Original videos remain hosted by Hugging Face and may require sign-in and acceptance of the model repository’s access terms. No credentials, cookies, or temporary signed URLs are included here.
- The previews are credited to Lightricks and are not relicensed under the application’s MIT license. Refer to the original model card for the upstream material and terms.
- No model weights were downloaded, and no LTX inference was run to create these previews.
- Pixel Upscaler has no example video/image on its current model card. Its README section says so explicitly; no substitute output is presented as an official demo.
